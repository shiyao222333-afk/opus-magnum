# 显示墙门户化设计方案：Dashy 当唯一大门（方案 B）

> 日期：2026-08-03 ｜ 状态：待用户确认 ｜ 依据：前端架构评审（50/100，双壳嵌套为混乱主因）
> 一句话：**Dashy 变成你唯一的"总指挥部大门"，巨作/熔知/凝华/B站/行动清单全部收编为大门里的应用**；三种视图分工：总览墙 / 干活台 / 极简页。

---

## 一、Dashy 能力盘点（4.5.5 实测 + 官方文档，方案能用什么）

| 能力 | 说明 | 本方案用途 |
|---|---|---|
| **三种视图** | Default 分区墙 / Workspace 左侧栏+iframe 内嵌 / Minimal 极简 tab | 总览 / 干活台 / 起始页 |
| **多页面** | pages 数组，导航栏自动生成页面切换按钮 | 每类工具一页（可选） |
| **布局** | auto / horizontal / vertical / masonry + colCount + displayData(cols/rows/itemSize) | 总览墙排版 |
| **打开方式** | sametab / newtab / top / **modal 弹窗** / **workspace 内嵌** + 全局默认 | 每工具定一种 |
| **主题定制** | 40+ 内置主题 + customColors(CSS 变量) + customCss + 外部样式表 + 背景图 + 字体 | 炼金五器主题 |
| **小部件 80+** | clock 时钟 / system-info / CPU / 内存 / 磁盘 / 天气 / RSS / 搜索框… | 总览墙"系统状态"区 |
| **状态检测** | statusCheck 每工具在线/离线小圆点 | 一眼看谁活着 |
| **全局搜索** | 顶部搜索栏秒开应用 | 好用的核心 |
| **快捷键** | item.hotkey 0-9 | 数字键秒开 |
| **子项** | subItems 折叠子菜单 | 收拢低频工具 |
| **图标** | FontAwesome / SimpleIcons / MDI / 自定义 URL | 每工具专属图标 |
| **隐藏组件** | hideComponents 可隐藏导航栏/页脚 | 极简模式 |

## 二、总体设计：三种视图各司其职

```
Dashy 4000（唯一大门）
├─ 视图① Default 总览墙（默认落地）—— 一眼看全部：系统状态 + 所有工具卡片
├─ 视图② Workspace 干活台 —— 左侧工具列表，点谁谁在右侧 iframe 里打开（不跳走）
└─ 视图③ Minimal 极简页（可选作浏览器起始页）—— 纯 tab + 搜索，最快
```

**核心规则**：
1. 所有工具**只从 Dashy 进**（巨作/熔知/凝华/B站/行动清单/文档）
2. 巨作不再内嵌 Dashy（删 /wall 页）→ **循环嵌套彻底消除**
3. 巨作去掉左侧抽屉 → **双左侧栏消除**（Dashy workspace 左侧管应用，巨作内部只需简单页签）

## 三、总览墙分区设计（Default 视图）

| 分区 | 内容 | 说明 |
|---|---|---|
| ⏰ 此刻 | clock 大时钟 + 日期（widget） | 好看第一眼 |
| 🖥️ 系统状态 | system-info + CPU + 内存 + 磁盘（widgets） | 本机资源一眼知 |
| ⚗️ 五器核心 | 巨作 / 熔知 / 凝华 / B站数据 / 行动清单 5 张卡 | **全部 target=workspace 内嵌**，带在线状态点 + 专属图标色 |
| 🔗 常用链接 | GitHub / 研究报告 / 显示墙方案文档 | 低频工具 target=newtab |
| 📚 知识仓库 | 熔知分区卡片（+ 受控词表/设置子项 subItems 折叠） | 熔知一个入口带子菜单 |

**卡片设计**（每工具一张）：

| 工具 | 图标 | 卡片色 | 打开方式 | 快捷键 | 状态点 |
|---|---|---|---|---|---|
| 巨作 | fa-crown | 金 #d4a017 | workspace | 1 | statusCheck ✅ |
| 熔知 | fa-book | 黄 #ffd866 | workspace | 2 | statusCheck ✅ |
| 凝华 | fa-wand-magic | 红 #ff6b6b | workspace | 3 | statusCheck ✅ |
| B站数据 | fa-chart-line | 粉 #ff9e3d | workspace | 4 | statusCheck ✅ |
| 行动清单 | fa-list-check | 青 #4ecdc4 | workspace | 5 | statusCheck ✅ |

> 炼金四相配色：馏析黑 / 炼真白 / 熔知黄 / 凝华红 —— 每张卡配所属相的颜色，五器身份一眼可辨。

## 四、干活台设计（Workspace 视图）

- `startingView: home`（默认落总览），但点任何 workspace 卡片自动切到干活台
- `workspaceLandingUrl: http://localhost:8501/`（进干活台默认开巨作）
- `enableMultiTasking: true`（后台保持已开应用，快速切换不断会话；卡了再关）
- 左侧栏 = 应用列表（自动从卡片生成），右侧 = iframe 干活区
- **内嵌兼容**：需各服务允许 iframe（X-Frame-Options）——巨作/熔知/凝华（NiceGUI 默认允许）✅、行动清单（已 ALLOWALL）✅、B站需实测（不行就 modal 弹窗打开）

## 五、极简页（Minimal 视图，可选）

- 纯 tab + 顶部搜索，秒开应用；可设为浏览器起始页（Dashy 官方定位）
- 用 `hideComponents` 隐藏多余组件，极净

## 六、视觉设计（好看）

**主题：五器炼金（alchemy）**
- 基础：深色系（沿 Dashy 深邃暗色，不突兀）
- 主色：金 #d4a017（炼金/哲人石感）
- 背景：深蓝黑 #0f1420 → 渐变（backgroundImg 或 customCss 渐变）
- 圆角：`--curve-factor` 12px（柔和现代）
- 卡片：`itemSize: large`（大卡显示描述）+ 每工具品牌色圆角卡
- 字体：保持系统中文友好（微软雅黑），标题可用 externalStyleSheet 引一款展示字体（如 LXGW WenKai 霞鹜文楷，免费 SIL OFL，有辨识度）
- logo：可放五器符号或炼金圆徽（user-data/web-icons/）

**小部件墙**（总览第一屏）：大时钟 + 日期 → 系统状态（CPU/内存/磁盘迷你表）→ 分区卡片墙

## 七、巨作改造清单（配合门户化）

| 改动 | 内容 |
|---|---|
| 删 /wall 页 | 巨作不再内嵌 Dashy（循环嵌套消除）；导航里的"显示墙"入口删除 |
| 去左抽屉 | 巨作页面改简洁顶部条：小 logo + 页签（周看板 / 摄入 / 总指挥）+ "回总指挥部"链接（跳 Dashy） |
| /hq 总指挥 | 保留（健康检测/连接器/开发进度），它是 Dashy 之下的"运维页" |
| 顶部加"总指挥部"链接 | target=top 跳回 Dashy（巨作被内嵌时也能跳出） |

## 九、风险与备选

| 风险 | 对策 |
|---|---|
| workspace 内嵌某服务被 X-Frame-Options 拦 | 该服务改 modal（弹窗）打开，或给服务加 ALLOWALL 头 |
| enableMultiTasking 内存开销 | 先开，卡了就关（配置一个开关） |
| 巨作裸页（去抽屉后）用户直接访问 8501 迷路 | 顶部条保留页签 + "回总指挥部"链，不迷路 |
| 显示墙方案文档里已写的"巨作内嵌 Dashy"内容 | 同步更新文档 |

## 十、验收标准（改完后）

1. 打开 localhost:4000 = 总览墙：大时钟 + 系统状态 + 五器卡片，一眼看清
2. 点任意工具卡 → 右侧工作区打开，左上侧栏可秒切其它工具
3. 数字键 1-5 秒开对应工具
4. 巨作页面无左抽屉、无显示墙页；顶部有"回总指挥部"
5. 无任何"Dashy 套巨作套 Dashy"路径（架构无环）
6. 6 服务全在线

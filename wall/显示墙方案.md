## 一、总体架构

```
巨作 8501（入口，不动现有功能）
└─ 新增子页面 /wall（显示墙）
    └─ 内嵌 Dashy 4000（成熟显示墙，self-hosted dashboard）
        ├─ 分区1：📊 周看板（阶段三移植）
        ├─ 分区2：📈 B站数据（Bili-Insights 8765，阶段二）
        ├─ 分区3：🔗 工具入口（熔知 8080 / 巨作 8501 / 研究报告…）
        └─ 后续：研究报告卡片 / 灵感生成物（内容方案之后定）
```

**三个新服务都走启动器统一管理**：`supervisor.py` 的 spawn 机制里 `python` 字段只是"解释器路径"，可以是任意可执行文件 → Dashy 填 node.exe、Bili-Insights 填 pythonw.exe → **零改动 supervisor.py**。效果：托盘菜单可见、网页启停面板可见、死了自动重启、独立日志。

## 六、Dashy 关键事实（官方文档确认，2026-08-03）

- **定位**：self-hosted personal dashboard（自托管个人仪表盘），把本地服务聚合到一个页面统一看——**原本就是显示墙的用途**
- **工作区视图**：应用在 Dashy 内部 iframe 打开，不用离开 Dashy，多任务同屏（`enableMultiTasking: true` 可保留多个应用同时开）
- **三种打开方式**：newtab / modal（弹窗）/ workspace（内嵌）
- **多页面 Pages**：conf.yml 定义多个子页面 → 每个研究对象一页
- **Widgets**：90+ 内置（时钟/天气/股票/RSS/系统监控…），含 Iframe Widget 和 HTML Embed Widget（可嵌自定义网页）
- **状态指示灯**：条目显示绿/红点，服务挂了红点提示
- **REST API**：可编程读取/更新配置 → 以后"对话生成报告→自动挂进 Dashy"可走 API
- **配置**：conf.yml（YAML），可用 UI 可视化编辑
- **启动**：开发 `yarn dev` / 生产 `yarn build && yarn start`（node 起 server）
